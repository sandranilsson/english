# English Nuance Glossary

A Swedish–English nuance glossary for academic writing.

## Publish with GitHub Pages
1. Create a GitHub repository and put these files in its `main` branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. Push to `main`. The included workflow deploys the site automatically.

The left navigation is generated in Swedish alphabetical order (A–Z, Å, Ä, Ö). Search matches both Swedish and English text.
